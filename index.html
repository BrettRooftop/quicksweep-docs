SAFETY

Project Safety

Non-Destructive Architecture
Strict Non-Destructive Operation Guarantee

QuickSweep was architected specifically for professional editing environments with zero risk to media assets:

  • Zero touching of existing bins: QuickSweep only files loose media sitting at the active scope. Folders and assets already arranged inside bins remain 100% untouched.
  • Zero disk modifications: Media files on your internal drive, external SSD, SAN, or NAS are never renamed, moved, or deleted. Operations are strictly metadata moves within Premiere Pro's project file.
  • Complete audit trail: The History panel logs every moved asset with its category, timestamp, and 1-click Source Monitor review.
  • Scoped targeting: In settings, you can restrict sweeping to a single sub-bin to test workflows safely.
01

Starting an Empty Project

Fresh Projects
Generate an industry-standard editorial hierarchy before importing media.

When you open an empty project with 0 bins in Premiere Pro, QuickSweep immediately presents the 1-click bin setup view.

  1. Launch QuickSweep (Window > UXP Plugins > QuickSweep).
  2. Select your preferred template from the Preset dropdown (e.g., QuickStart Standard).
  3. Review the live preview table showing the bins to be created and their mapped asset categories.
  4. Click Create Bin Structure.
Creating a Custom Structure Instead: Don't want to use QuickStart Standard? Select ＋ Create New Preset... in the dropdown (or click the edit pencil icon) to design your own custom folder tree right in the Template Builder. You can also click Configure Bin Mappings Manually at the bottom of the card.
Result: Premiere instantly creates numbered bins: 01_Sequences (with Nests), 02_Footage, 03_Audio (with Music & SFX), 04_Graphics (with AE, Stills, & Styles), and 05_Elements (with Adjustments, Captions, Mattes, & Black Video), automatically filing any loose media.

02

Setting up an Existing Project

Smart Detection & Active Projects
Smart preset detection for existing projects: Set It and Forget It.

When opening an active project, QuickSweep scans your bin structure and adapts automatically:

Full Preset Match: If an existing project matches one of your saved presets, QuickSweep skips setup completely and opens straight to the active dashboard.
Partial Match: If a project contains some bins from a preset, QuickSweep detects the similarity, highlights existing vs. missing folders, and lets you click Create Missing Bins to top up the structure—or Use Matched Bins Only to sort into what's already there.
Custom Structures: For unique project trees, click Configure Bin Mappings Manually to map your existing bins without clutter.
  1. Open Settings (gear icon in header) and review destination bins in Bin Mappings.
  2. Optionally set Sweep Scope to target the entire project root or a specific folder.
Figure 2: Bin Mappings & Scope View
One-Click Manual Sweep (BIN IT!)

When you prefer hands-on control over your sorting rhythm, leave Auto-Sweep toggled OFF. The signature blue BIN IT! button remains active on your dashboard:

  1. Import new footage, audio, graphics, or create project elements at any time.
  2. When you're ready to organize loose assets, click BIN IT! on the main dashboard.
Result: All loose assets sitting at the active scope fly instantly into their designated bins in a single click. Existing sub-bins and timeline edits remain completely untouched.

03

Background Auto-Sweep

Zero Maintenance
Automate organization so your project stays clean while you edit.

Auto-Sweep eliminates manual maintenance entirely. Every newly imported file is filed automatically without interrupting playback.

  1. Ensure your bins are mapped in the Settings view.
  2. On the main screen, toggle the Auto-Sweep switch to ON.
Result: QuickSweep silently monitors your project in the background every 5 seconds. Whenever you import footage, download a music track, or render a nest, it files itself automatically.

CORE

Capabilities & Editorial Superpowers

History Log & 1-Click Source Monitor Review

Wondering where a file went? Click the Moved items icon (document icon in the header) to view recent sweeps. QuickSweep provides instant visual transparency for every moved asset:

  • Asset Chips: Displays the item name, detected asset category, destination bin, and sweep timestamp.
  • 1-Click Inspection: Click any asset pill to load that media file directly into your Source Monitor for immediate review and playback.
Figure 5: Moved Items History & Review
Custom Template Builder & Un-assigned Utility Bins

Tailor bin structures to your facility, agency, or personal workflow with deep folder nesting and utility folders:

  • Hierarchical Nesting: Use >, /, or \ syntax in bin names to create deep folder trees in one pass (e.g., 03_Audio > Music, 03_Audio > SFX). Click Save & Apply Preset to commit.
  • Un-assigned Utility Bins: Use the Un-assigned section at the bottom of the Template Builder to add custom utility or staging bins (e.g., 00_Exports, 06_VFX, 07_Documents) so they are created alongside mapped bins without auto-routing media into them.
  • Preset Management: Save unlimited custom presets, rename existing templates, or delete outdated structures with a single click.
Figure 6: Custom Template Builder Overlay
Workflow Preferences & Timeline Label Colors

Fine-tune sweeping behavior and visual styling under Settings > Preferences:

  • Auto-Create Missing Bins: When toggled ON, QuickSweep automatically generates any missing destination folders during a sweep. When OFF, assets mapped to missing bins are safely bypassed.
  • Label Color Themes: Automatically color-code your timeline clips upon sweeping based on asset category. Choose from 4 curated palettes: Default, Classic, Vibrant, or Editorial.
  • Appearance & Layout: Customize UI styling, collapse or expand stats counters, or reset session tracking metrics anytime.

FAQ

Reference & Common Questions

Disk Safety ►
QuickSweep never alters files on disk. Operations are strictly confined to Premiere Pro's project metadata. Local drives, shared SAN/NAS, and cloud caches remain completely unchanged.
Sweep Scope ►
In Settings > Bin Mappings, you can restrict organization to a specific sub-folder rather than the entire project root.
Unmapped Asset Types ►
Any file category left without a destination bin is ignored and remains in its current position.
Label Colors ►
In Settings > Preferences, enable Label colors to automatically assign Premiere Pro label colors to swept items by category (Footage, Music, SFX, Graphics). You can select from Default, Classic, Vibrant, or Editorial color themes to match your project preferences.
Auto-create Missing Bins ►
In Settings > Preferences > Workflow, toggle Auto-create missing bins ON so unmapped or non-existent destination folders are created on the fly during a sweep. When OFF, assets mapped to missing bins are safely skipped.
Re-organizing Later ►
Changed your mind on a destination? Remap any asset category in Settings > Bin Mappings and click BIN IT! again—or drag clips back to the project root to re-sort them.
Resetting vs. Deleting Presets ►
Clicking Reset Mappings clears only the current project's temporary folder links without touching or deleting your saved global presets.
